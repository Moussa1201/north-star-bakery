# North Star Bakery

Four-page bakery website for Introduction to Web Development Touchstone 3.
This continues the semantic HTML project from Touchstone Task 2 with a
shared external stylesheet and responsive Flexbox layouts.

## Pages
- Home: index.html
- Products: products.html
- About: about.html
- Contact and preorder practice form: contact.html

Location: 123 Main Street, San Francisco, CA 94102.
Business details and prices are sample content for the assignment.
The form demonstrates built-in validation; it does not process requests.

## Design
Cream #FFF8F0, brown #6B3E26, peach #D88C5A, charcoal #2F2A26.
Georgia headings and Arial body text. Mobile-first layout with a 48rem
media query. Supplied images and welcome audio are in media/.

## Preview in Codespaces
Run `python3 -m http.server 8000` and open forwarded port 8000.
Check navigation, audio, form validation, and widths of 375px, 768px,
and 1280px. Keep the media folder and styles.css beside the HTML files.
